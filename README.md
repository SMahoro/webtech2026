# LadeSpot.de
Dieser kleine Webdienst soll das Finden von E-Auto-Ladesäulen in den 84 größten Städten Deutschlands erleichtern.
Favoriten sollen nach dem Einloggen speicherbar sein.
Als Umfangserweiterung steht das Anzeigen von Verfügbarkeiten im Raum.

Um die Webseite vernünftig darstellen zu können braucht es einen lokalen Server.
Diser  lässt sich über das Terminal in VS Code starten mittels:
```
python -m http.server 8000
```
Im Browser ist er dann unter dieser Adresse erreichbar:
```
localhost:8000
```
